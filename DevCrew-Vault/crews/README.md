# DevCrew Teams & Crews

This folder holds human-authored definitions of agent crews and team compositions.

## How to Create a Crew Note
1. Copy `_TEMPLATE.md` to a new note named after your crew (e.g. `Security-Audit-Crew.md`).
2. Link the selected skills from `map/skills/` that this crew employs.
3. Define the crew mission, roles, trigger workflows, and review gates.
