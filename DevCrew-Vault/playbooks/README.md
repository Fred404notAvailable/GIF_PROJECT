# DevCrew Playbooks

This directory contains human-authored execution playbooks and standard operating procedures (SOPs) for development, security response, deployments, and testing.

## How to Create a Playbook Note
1. Copy `_TEMPLATE.md` to a new note named after your playbook (e.g. `Incident-Response-Playbook.md`).
2. Link the participating skills from `map/skills/` and any crews from `crews/`.
3. Document step-by-step procedures, rollback criteria, and verification checklists.
